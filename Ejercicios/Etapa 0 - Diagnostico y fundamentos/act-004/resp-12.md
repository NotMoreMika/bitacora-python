# Respuesta

Para cantidad de negativos, positivos y ceros, necesito mantener un contador.

Para la suma de los positivos y el promedio necesito un acumulador para cada uno, donde para el promedio se suman todos los valores.

Para el mayor valor y el menor valor necesito guardar los que cumplen la condicion de superar el valor maximo o minimo

Para la cantidad de maximo que se repiten necesito un contador asociado al valor maximo

Para la lista de valores pares necesito filtrar.
