# Respuesta

Para los siguientes casos debe comportarse:

- lista vacía: No debe aceptarse ya que no existe ningun valor
- un solo elemento: No debe aceptarse ya que solo existe un valor y este a su vez seria el mayor y el segundo mayor
- todos los elementos iguales: No deben aceptarse listas con todos los elementos iguales ya que no existe un segundo elemento mayor, todos son el mayor.
- solo existe un valor distinto: Este caso es distinto si hay 2 valores distintos uno logicamente es el mayor y otro el menor.

A menos que sea necesario lo ideal seria solo procesar listas con 2 valores distinto. En caso de que no se cumpla asi, indicarle al usuario, como una advertencia.
